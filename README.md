# SmartSpace — магазин смартфонов

Локальный сайт и учебный проект магазина смартфонов. Сайт работает без сервера,
JavaScript-зависимостей и внешних изображений. Все расчёты выполняются в браузере;
отчёт хранится в памяти открытой вкладки.

## Запуск сайта

Откройте `index.html` в любом современном браузере. В Windows это можно сделать
из папки проекта командой:

```powershell
Start-Process .\index.html
```

Для точного совпадения шрифтов требуется интернет; без него браузер использует
системный шрифт. Все функции сайта доступны и без загрузки веб-шрифтов.

## Возможности сайта

- каталог смартфонов с категориями и фильтрами;
- расчёт скидок по сумме покупки и наличию карты лояльности;
- проверка возраста, статуса аккаунта, бюджета и условий покупки;
- персональная рекомендация по бюджету, памяти, автономности, камере и играм;
- оценка выбранной модели по баллам;
- финансовый анализ доходов и расходов;
- калькулятор тарифов сервисного обслуживания;
- оценка риска заказа по четырём параметрам;
- демонстрационная проверка логина и статуса аккаунта;
- отчёт с датой, временем и результатами действий в текущей вкладке.

Демо-логин: `smart`, пароль: `phone2026`. Это учебная демонстрация — сайт не
подключён к базе данных или платёжному сервису.

## Исходный проект Java

Java-версия сохранена в каталоге `src`. Для её компиляции необходим JDK 21:

```powershell
New-Item -ItemType Directory -Force out
javac -encoding UTF-8 -d out src\*.java
java -cp out Main
```
